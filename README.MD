
# FIFA World Cup 2026 Performance Analysis

## Descripción

Este proyecto tiene como objetivo analizar estadísticamente el rendimiento de los jugadores participantes en el Mundial de Fútbol 2026. Mediante técnicas de Análisis Exploratorio de Datos (EDA), se examinan variables ofensivas, defensivas, físicas y de rendimiento general para identificar patrones, tendencias y hallazgos relevantes dentro del torneo.

Los resultados obtenidos permiten comprender mejor el comportamiento de los jugadores y equipos a lo largo de la competición, proporcionando información útil para la interpretación y evaluación del desempeño deportivo.
